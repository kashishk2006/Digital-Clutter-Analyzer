# 🗂️ Digital Clutter Analyzer

Digital Clutter Analyzer is a Streamlit-based application that analyzes a folder and identifies digital clutter such as old files, large files, and duplicates.

## ✨ Features

- 📁 Analyze any folder on your computer
- 📊 View total files and storage used
- 📂 Analyze storage by file type
- 🔴 Detect large files
- 🏆 Identify the top 5 largest files
- 🕒 Detect files older than 180 days
- ♻️ Find duplicate files
- 📊 Calculate a Clutter Score
- 💾 Estimate potential storage that can be freed
- 🧠 Get smart cleanup suggestions
- 🗃️ Categorize files
- 🚨 Get cleanup priorities
- 🔄 Restart analysis easily

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Tkinter

## ▶️ How to Run

1. Install the required packages:

pip install -r requirements.txt

2. Run the application:

py -m streamlit run app.py

## 🎯 Purpose

The project helps users understand what is taking up space on their computer and identify files that may need cleanup, without automatically deleting any files.
